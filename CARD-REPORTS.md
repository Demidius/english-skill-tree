# Жалобы на ошибки в карточках

## Для ученика

В карточках лексики (в том числе при повторении и в списках слов) и на странице грамматического правила есть кнопка **«Пожаловаться на ошибку»**. Открывается окно с необязательным описанием. После нажатия «Отправить жалобу» в коллекцию Firestore `cardReports` записываются:

- вид карточки (слово или правило), ID темы и ID слова;
- английский и русский текст в момент отправки;
- название темы и уровень/урок;
- необязательное описание проблемы;
- UID пользователя и имя из его профиля;
- время отправки с сервера Firebase;
- статус `new`.

Для отправки нужен вход в зарегистрированный аккаунт. В гостевом офлайн-режиме запись не поддерживается.

## Для администратора

Откройте **https://demidius.github.io/english-skill-tree/reports.html** или ссылку «Все жалобы на карточки» в настройках администратора.

Страница разрешена только аккаунтам с документом `accessAdmins/{uid}`, как и существующий раздел управления данными. По умолчанию показываются все **новые и находящиеся в работе** жалобы. Можно фильтровать по статусу и периоду (7/30 дней), видеть несколько жалоб на одну карточку, сохранять статус (`new`, `in_progress`, `fixed`, `dismissed`) и комментарий администратора. Список можно скачать в CSV или скопировать в текст, чтобы передать на проверку в ChatGPT. При наличии более 200 записей нажмите «Загрузить ещё» до полной загрузки перед экспортом.

Проверка **не вносит исправления автоматически**. Изменения в карточках делаются отдельно по запросу после проверки исходных данных. Имя автора и исходный текст жалобы пользователь после отправки изменить не может.

## Публикация правил безопасности

**Обязательно**: GitHub Pages не развёртывает Firestore Rules. После обновления репозитория нужен один ручной деплой из локального клона, с доступом к Firebase-проекту `english-skill-tree-01`:

```sh
npm install
npx firebase login
npx firebase use english-skill-tree-01
npx firebase deploy --only firestore:rules --project english-skill-tree-01
```

Проверка тестов с эмулятором перед деплоем: `npm run test:access` (требует Java и установленного Firebase CLI). Новая коллекция не будет доступна для отправки, пока правила не опубликованы.

Использовать сайт для проверки доступности нужно под зарегистрированным пользователем, не под локальным гостем. После деплоя отправьте тестовую жалобу и убедитесь, что она видна в журнале администратора.
