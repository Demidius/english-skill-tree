# Почта для восстановления

Вход по-прежнему по нику и паролю (технический адрес `ник@users.skilltree.app`).
Настоящая почта хранится отдельно, в `accountPrivate/{uid}`: её видят только владелец и администратор,
друзья и публичные ссылки — нет. Адрес записывают только Cloud Functions из `functions/`;
сам пользователь может лишь отказаться от почты (`emailOptOut`).

- После входа без почты появляется окно «Привяжи почту» (или галочка «Не хочу указывать почту»; «Позже» — до следующего входа).
- В настройках, в карточке «Почта для восстановления», почту можно добавить или сменить. На новый адрес приходит письмо
  с ником и ссылкой на сайт, на старый — уведомление о смене.
- «Забыл пароль»: ссылка сброса Firebase уходит на привязанную почту. «Забыл ник»: на почту приходят все ники с этим адресом.
- Пароль в письма не попадает: Firebase хранит только его хэш.
- Ограничения: смена почты 5 раз в сутки, запросы восстановления 3 раза в час на ник или адрес (`mailLimits`, только сервер).

## Включение (один раз)

1. Firebase Console → перевести проект на тариф **Blaze**. Cloud Functions работают только на нём.
   При таком объёме всё укладывается в бесплатную квоту; поставить бюджетное оповещение, например на $1.
2. Почта-отправитель: в Google-аккаунте включить двухэтапную проверку и создать **пароль приложения**.
3. Секреты (в Git не попадают):
   `pnpm exec firebase functions:secrets:set SMTP_USER` — адрес Gmail,
   `pnpm exec firebase functions:secrets:set SMTP_PASS` — пароль приложения.
4. `cd functions && npm install && cd ..`, затем
   `pnpm exec firebase deploy --only functions,firestore:rules --project english-skill-tree-01`.
5. Authentication → Settings → Authorized domains: должен быть `demidius.github.io`.
   Authentication → Templates → язык шаблонов «Русский» (страница ввода нового пароля).
6. По желанию: Firestore → TTL-политика для коллекции `mailLimits`, поле `expiresAt`.

Пока функции не развёрнуты, сайт работает как раньше; кнопки восстановления отвечают «Отправка писем пока не настроена».
В эмуляторе (`firebase emulators:start --only auth,firestore,functions`) письма не отправляются, а печатаются в лог.
